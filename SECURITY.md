# Security policy

This project's main promise is that an AI client connected through it cannot trade. A way to place, modify or close an order, to run with an account that is allowed to trade, or to write files outside `MT5_EXPORT_DIR` is a security issue.

Please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue. You can expect a first reply within a week.

Supported version: the latest release.
